# Pomodoro App

This is a new pomodoro PWA to track activities throughout the day

## Tech Stack

- React
- Parcel
- Redux
- Octicons
- Typescript
- Jest
- React Testing Library

## File Structure

```
src/
 |-- assets/
 |-- public/ -- index.html
 |-- components/
 |-- constants/
 |-- helpers/
 |-- store/
 |-- types/

```

## Coding Conventions

1. Never use `any` as a type
2. Use clear variable names
3. Keep functions small
4. Use CLEAN code design

## Testing

Create tests before making changes. It should use [TDD](https://gist.github.com/w3cj/4fdc714f845180a26d236720e3dbfc71). After making changes, be sure that all tests passes running `npm run test`
